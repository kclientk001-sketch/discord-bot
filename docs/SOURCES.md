# Nguồn kiểm chứng

Đối chiếu ngày 2026-10-02. Nguồn chính thức xác nhận cơ chế API và giới hạn; chúng không chứng minh credential của người dùng hoặc endpoint legacy thực tế còn hoạt động. Phiên bản npm được hỏi từ registry và ghi theo install trong DEPENDENCIES.md.

| Nguồn gốc                                                                                                                        | Cơ chế đã dùng / giới hạn                                                                                                                                                      |
| -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Discord OAuth2](https://docs.discord.com/developers/topics/oauth2)                                                              | Authorization Code, form-urlencoded token endpoint, state, identify, bot khác tài khoản thường; activities.write không khả dụng cho app thông thường                           |
| [Discord public client](https://discord.com/assets/web.ea428454da038edc.js) | Nguồn chính do Discord phát hành; kiểm tra tĩnh ngày 2026-10-02: LOGIN `/auth/login`, LOGIN_MFA(type) `/auth/mfa/{type}`, payload password và TOTP, các cờ MFA và ticket. Không phải API public được hỗ trợ; không phân phối bundle gốc trong ZIP. Hash/bằng chứng tại LOGIN-CLIENT-VALIDATION.json |
| [Discord MFA engineering](https://discord.com/blog/how-discord-modernized-mfa-with-webauthn) | TOTP, SMS, backup và WebAuthn là các yếu tố khác nhau; WebAuthn gắn với Discord domain. Form localhost chỉ triển khai TOTP; MFAv2 elevation cookie không được coi là user token |
| [Discord Authenticator](https://support.discord.com/hc/en-us/articles/26304482627095-Using-an-Authenticator-App-on-Discord) | Cách dùng Authenticator; người dùng cung cấp mã hiện tại, không cung cấp seed/QR cho ứng dụng này |
| [Discord User](https://docs.discord.com/developers/resources/user)                                                               | GET users/@me, identity, bot flag, avatar                                                                                                                                      |
| [Discord self-bots](https://support.discord.com/hc/en-us/articles/115002192352-Automated-User-Accounts-Self-Bots)                | Cấm tự động hóa tài khoản thường, có thể chấm dứt tài khoản                                                                                                                    |
| [Discord rate limits](https://docs.discord.com/developers/topics/rate-limits)                                                    | Header Remaining/Reset-After và Retry-After/JSON retry_after; dừng request invalid auth                                                                                        |
| [Discord Gateway Events](https://docs.discord.com/developers/events/gateway-events)                                              | Bot presence và Activity, khác Custom Status; không ACK riêng cho từng presence update                                                                                         |
| [Discord Userdoccers — User Settings](https://docs.discord.food/resources/user-settings)                                         | **Nguồn reverse engineering gốc, không phải tài liệu Discord chính thức**: GET/PATCH legacy settings, custom_status text tối đa 128, emoji/expiry; đã deprecated sang protobuf |
| [Spotify currently-playing](https://developer.spotify.com/documentation/web-api/reference/get-the-users-currently-playing-track) | Scope user-read-currently-playing, item/progress_ms/is_playing; không cần quyền điều khiển playback                                                                            |
| [Spotify PKCE](https://developer.spotify.com/documentation/web-api/tutorials/code-pkce-flow)                                     | SHA-256 challenge, verifier, authorization code và refresh                                                                                                                     |
| [Spotify Redirect URIs](https://developer.spotify.com/documentation/web-api/concepts/redirect_uri)                               | HTTP được phép với loopback IP, localhost không chấp nhận                                                                                                                      |
| [Spotify Get Track](https://developer.spotify.com/documentation/web-api/reference/get-track)                                     | Metadata từ URL là metadata, không phải phiên phát                                                                                                                             |
| [Spotify quota modes](https://developer.spotify.com/documentation/web-api/concepts/quota-modes)                                  | Premium app owner, allowlist, giới hạn người dùng, QUOTA_EXCEEDED nằm trong error.reason                                                                                       |
| [Spotify quota July 2026](https://developer.spotify.com/blog/2026-07-23-web-api-quota-updates)                                   | 25 Client IDs, quota chung developer; cập nhật mới hơn giới hạn 1 Client ID trong tài liệu February cũ                                                                         |
| [Spotify refresh expiration](https://developer.spotify.com/blog/2026-06-18-refresh-token-expiration)                             | Refresh token 6 tháng, invalid_grant cần discard và đăng nhập lại                                                                                                              |
| [Spotify migration February 2026](https://developer.spotify.com/documentation/web-api/tutorials/february-2026-migration-guide)   | Hạn chế Development Mode và grandfathering app cũ; phải đọc cùng cập nhật July                                                                                                 |
| [Chrome content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)                          | MAIN/isolated world, messaging thay vì chia sẻ credential cho page script                                                                                                      |
| [Chrome Storage API](https://developer.chrome.com/docs/extensions/reference/api/storage)                                         | storage.session và TRUSTED_CONTEXTS; không localStorage cho credential                                                                                                         |
| [YouTube Data API](https://developers.google.com/youtube/v3/docs)                                                                | Metadata video, không cung cấp currentTime/paused của phiên tab đang nghe                                                                                                      |
| [HTMLMediaElement — chuẩn WHATWG](https://html.spec.whatwg.org/multipage/media.html)                                             | currentTime, duration, paused, ended, playbackRate trong bridge                                                                                                                |
| [LRCLIB tài liệu](https://lrclib.net/docs) / [mã nguồn provider](https://github.com/tranxuanthang/lrclib)                        | API search, syncedLyrics/plainLyrics; nguồn public không cấp quyền tác giả toàn catalog                                                                                        |
| [Node releases](https://nodejs.org/en/about/previous-releases)                                                                   | Node 24 LTS, Node 26 còn Current khi đối chiếu                                                                                                                                 |
| [Node SQLite](https://nodejs.org/api/sqlite.html)                                                                                | DatabaseSync tích hợp cho config/lyrics/cache                                                                                                                                  |
| [Keyring upstream](https://github.com/Brooooooklyn/keyring-node)                                                                 | OS credential store, native optional dependency                                                                                                                                |

Không scrape nội dung tài khoản, không đọc browser session để tìm token. Endpoint legacy được đóng gói như adapter thử nghiệm và phát hiện capability khi chạy, không tuyên bố chính thức hỗ trợ Custom Status qua OAuth identify.
